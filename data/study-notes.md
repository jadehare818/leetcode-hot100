## `#416` 分割等和子集

| | |
|---|---|
| 分类 | 动态规划 |
| 难度 | 🟡 中等 |
| 状态 | ⚪ 未刷 · 尚未进复习队列 · 下次复习 — |
| 最近编辑 | 2026-08-31 · [🔗 力扣](https://leetcode.cn/problems/partition-equal-subset-sum/) |

**💡 思路**

> 先求和，和为奇数直接返回false；把一半定为target。维护dp[i]=是否存在和为i的元素和；背包01思想。
> [1, 6, 4, 7]
> target=13
> target=3
> 01背包思想：遍历每个物品，然后从高到低放进背包。
> 可以这么理解（省流：俄罗斯方块 之 一个新方块掉下来后每次碰到一个物品就记录一下头顶高度，最后落到底部 版）：
> 这是背包：
> ____
> |    |
> |    |
> |    |
> |    |
> |    |
> ----
> 背包竖着放，高度是target。我们把第一个高度为nums[0]的物品从书包的入口也就是上方放进来，像是俄罗斯方块一样掉进来，那这个物品的顶部所在的高度就是从target慢慢掉到nums[0]（即遍历是 for height in range(target, nums[0]-1, -1)）：
> ____   ____
> |口 |   |    |
> |    |   |    |
> |    |   |    |
> |    |   |    |
> |    |   |口|
> ----   ----
> 之后，我们让第二个物品(画做♦️♦️），高度为nums[1]的物品，也掉进来；这个时候它就是从target慢慢掉到nums[1]；同时，在它正好摞在物品0上面的时候，所在高度是nums[0]+nums[1]；
>             1       2
> ____   ____   ____
> |♦️|   |    |   |    |
> |♦️|   |    |   |    |
> |    |   |♦️|   |    |
> |    |   |♦️|   |♦️|
> |口|   |口|   |♦️| (这里口和♦️都在只是不好画)
> ----   ----   ----
> 也就是说，对于这俩物品来说，可以实现：nums[0],nums[1],nums[0]+nums[1]三种高度
> 
> 以此类推，我们不断这样放新的物品进去，每次高度的遍历是从target一直到这个物品的高度，也就是for j in range(target, num-1, -1)；
> 这样，每次一个物品放下来，分别摞在之前进来的不同的物品上面、或者直接放到最底部，这些所有的它头顶的高度，都会去更新我们的dp[]。
> 
> 到最后，我们只要去看，是否有物品进来后：它摞在别的物品上时头顶所在的高度 / 它放到最底部后头顶所在的高度，等于我们的目标target也就是这个书包的容量；即可得出是否有物品之和=target。
